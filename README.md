# Homework Docker - DevOps with Docker

This repository contains the exercises and configurations for the University of Helsinki's DevOps with Docker course.

## Live Deployment
The application is automatically deployed via a CI/CD pipeline built with GitHub Actions.

🔗 **Live Application URL:** [https://fly.dev](https://fly.dev)

## Features Included
* Automated testing and environment validation
* Continuous integration and multi-stage container optimization
* Automated image builds pushed directly to Docker Hub (`lordsikil/express-app`)
* Continuous deployment to Fly.io micro-VMs on every commit to the main branch
